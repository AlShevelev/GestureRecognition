# Demonstration of the “$1 Unistroke Recognizer” Algorithm

This repository demonstrates the operation of the [$1 Unistroke Recognizer gesture recognition algorithm](https://depts.washington.edu/acelab/proj/dollar/index.html). This algorithm recognizes gestures with a high degree of reliability. It is easy to understand and requires only a single example to train it to recognize a specific gesture.

The algorithm’s operation consists of two phases: training and recognition. This repository contains both phases of the algorithm’s operation (the Parsing and Recognition directories, respectively).

The Parsing directory contains an AI-generated Python script that trains the algorithm using reference images.

The Recognition directory contains an Android app (generated by AI and manually refined) that recognizes drawn gestures based on the training data.

This repository serves as an illustration for an article that is currently being written.
